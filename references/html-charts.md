# HTML 周报：每日投入堆积图

用户需要时长图表时读取本文件。以下为可覆盖的报告预设；已有页面只改用户指定部分，不因换柱色而重设整页主题。

## 布局与数据

- 在主要任务之后、每日活动表之前放“每日投入分布”。横轴为本地日期，纵轴为小时。每根柱的高度等于当天各项目用时之和，柱顶显示当天总小时数。
- 使用普通时长堆积柱，不默认做每根等高的 100% 堆积图。百分比是标签，不改变柱子的时长尺度；用户明确要求百分比轴时才归一化。
- 为项目使用稳定 ID。先按全周累计用时降序形成统一项目顺序；所有日期自底向上沿用此顺序，缺少的项目跳过。相同用时沿用原顺序。不要每天按占比重新排列，否则同一项目会在柱间跳动。
- 柱内标签 = 项目当日用时 / 当天全部已选项目用时 × 100%。图例右侧标签 = 项目全周用时 / 全周全部已选项目用时 × 100%。分别标明“占当天比例”和“占全周投入”，不混用分母。
- 以同一份项目日数据生成柱图、每日活动表、项目详情和 CSV。新增项目、重分归属或调整时间后一起更新；不得直接叠加已有公共支撑时段。
- 真实零用时不绘制色块；记录缺失不当零，不计算未知分母。舍入前计算百分比；标签通常保留一位小数，舍入之和可能略偏离 100%。

## 配色预设

按统一项目顺序分配以下十色；项目颜色跨日期固定，图例色块必须对应。

| 顺序 | 颜色 |
|---|---|
| 1 | #9E0142 |
| 2 | #D53E4F |
| 3 | #F46D43 |
| 4 | #FDAE61 |
| 5 | #FEE08B |
| 6 | #E6F598 |
| 7 | #ABDDA4 |
| 8 | #66C2A5 |
| 9 | #3288BD |
| 10 | #5E4FA2 |

这是一组红、橙、黄、绿、蓝、紫的分类配色，不表达好坏或数值大小。超过十项时扩展可辨识颜色或提供筛选，不循环使用同色造成歧义，也不擅自合并不同研究项目。

深红、红、蓝、紫柱块可使用白字；橙、黄、浅绿柱块使用深色文字（如 #28332F）。检查实际对比度与字号。色块之间用细白线分隔，不添加 3D、渐变或发光效果。

把图表颜色保存在独立的 chartPalette 映射中，不覆盖页面的项目卡片、活动表、标题或背景变量。仅要求调整柱状图配色时，同步图例即可，其他区域保持原样。新报告需要全页统一色系时再按用户要求处理。

## 文字、图例与交互

- 白色图表面板、浅灰水平网格；轴刻度和标签使用 Arial 加中文系统字体回退。整体沿用原页面排版，避免大段说明。
- 色块足够高时直接显示百分比；较薄色块不强塞文字，通过悬停、键盘聚焦或点按显示日期、项目全名、时长及占当天百分比。
- 每个交互色块提供可访问名称与可见焦点；提示框限制在视口内，可用 Escape 关闭。颜色不能成为唯一的信息来源。
- 图例依统一项目顺序排列，宽屏可用三列，窄屏用两列；右侧显示各项目占全周投入的百分比。
- 周总时长、日期与数字优先使用 Arial；现有页面的其他字体遵循用户原有设置。
- 手机允许图表容器横向滚动，避免整页溢出；打印时图表完整显示。基础数据与 SVG 可内嵌在 HTML，不依赖远程脚本或外部字体。
- 估算值继续标“约”，在折叠的记录说明中写清口径，不包装成精确计时。

## 检查

核对每日柱高、全周合计、两个百分比分母、固定堆叠顺序及图例映射。检查最长项目名称、极小色块、未知日期和窄屏布局。确认改变柱色没有连带修改图表之外的配色。不要为公开样例使用真实历史、姓名、稿件标题或本机路径。
